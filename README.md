## 🌟 核心特性 (Features)

- **全平台支持**：针对 Windows、macOS (Apple Silicon & Intel)、Android 以及 iOS 深度原生调优。
- **现代化视觉与终端体验**：
  - 沉浸式毛玻璃侧边栏与现代移动端微胶囊导航底栏。
  - 多套精选终端主题与皮肤方案，完美适配明暗模式。
  - 多会话标签栏，支持左右分屏、拖拽与上下文快速切换。
- **强大的主机与连接管理**：
  - 分组管理、密码/私钥认证、跳板机支持。
  - 连接自动执行脚本与一键批量管理。
- **高效内置 SFTP 双栏文件管理器**：
  - 本地与远程无缝拖拽上传/下载、断点续传。
  - 目录书签、极速导航、文件内联预览与实时编辑器。
  - 保持长连接与心跳保活，告别频繁重连。
- **端口转发与隧道映射**：
  - 本地转发、远程转发与动态 SOCKS 代理支持。
- **多端云同步 (Cloud Sync)**：
  - 基于 WebDAV / 私有云盘的零冲突配置安全同步，支持凭据与主机加密隔离。
- **移动端专属优化**：
  - 专为触屏设计的终端辅助功能栏、快捷键盘、手势选区与光标移动。
  - iPad / 平板电脑自适应桌面工作台布局。
